## Branching Policy (Required)

Each lab must be implemented in a **separate branch**.

---

## 🔄 Workflow

### 1. Create a new branch for the lab

```bash
git checkout -b lab-XX
```

### 2. Implement your changes and commit

```bash
git add .
git commit -m "feat: implement lab XX"
```

### 3. Push the branch to remote

```bash
git push origin lab-XX
```
